# 活下去

SillyTavern 扩展：为死亡回归系统提供原生提示词顺序接线。

安装方式：在 SillyTavern 扩展管理中使用本仓库地址：

`https://github.com/dummy-battery/huoxiaqu`

当前仓库用于测试阶段交付，版本以 `manifest.json` 为准。

## 原生楼层版本

更新本扩展时，请同时导入配套的最新版活下去综合脚本。扩展读取脚本已保存的存档点、死亡与回归楼层标记，按当前可见窗口组织提示词。没有可用标记时保留酒馆原提示词。

使用酒馆原生扩展安装与更新入口；当前版本入口为 `index.js`。

手工重新生成与删除的回归事务保护需要本扩展 0.2.1 或更高版本，并同时导入配套的最新版综合脚本。已安装旧版时，请在酒馆原生扩展管理中更新后刷新页面。旧历史没有撤销凭据时会拒绝受保护操作；脚本或 Slash 直接调用生成不属于这项保护。
